WezTerm配置与使用指南—Windows、PowerShell、WSL与多窗格工作流

发表于2026-07-31|更新于2026-07-31|开发工具
|总字数:5.8k|阅读时长:21分钟|浏览量:

WezTerm 是一个使用 Rust 编写、支持 GPU 加速和 Lua 配置的跨平台终端模拟器。本文介绍的不是 WezTerm 默认配置，而是基于 KevinSilvester/wezterm-config 调整后的 Windows 配置。它将 PowerShell 7 作为默认 Shell，同时接入 Windows PowerShell、Command Prompt、Git Bash 和 Ubuntu WSL，并提供背景图片、状态栏、标签页状态、多窗格操作以及一套以 Alt 为核心的快捷键。

默认 Shell PowerShell 7
WSL Ubuntu，用户 lixiao，登录 Shell 为 Bash
Git Bash E:\Git\bin\bash.exe
字体 JetBrainsMono Nerd Font

如果在其他计算机上使用本文，Shell 路径、WSL 发行版名称和用户名必须按照实际环境修改，不能原样复制。

一、先理解 WezTerm 的工作模型

1. Window、Tab 与 Pane

WezTerm 的界面可以分为三层：

  • Window 是一个独立的 Windows 桌面窗口。
  • Tab 是窗口顶部的标签页，一个窗口可以包含多个 Tab。
  • Pane 是 Tab 内部的终端区域，一个 Tab 可以继续拆分为多个 Pane。

这三个概念对应三组不同操作。例如，Alt+N 新建 Window，Alt+T 新建 Tab，Alt+\ 拆分 Pane。关闭 Pane 和关闭 Tab 也使用不同快捷键。

2. Shell、Domain 与 Launcher

Shell 是 Pane 中实际运行的命令解释器，例如 PowerShell 7 或 Bash。Domain 则描述 Shell 在哪里运行：

  • DefaultDomain 表示 Windows 本地环境；
  • wsl:ubuntu-bash 表示 Ubuntu WSL 环境；
  • 配置还可以扩展 SSH Domain 和 Unix Domain。

Domain 不只是启动命令的别名。WezTerm 可以借助 Domain 和 Shell Integration 跟踪当前工作目录，使同一 Domain 中创建的新 Tab 或 Pane 更容易延续原环境。

Launcher 是统一的启动入口。当前配置既可以通过 F3 打开 WezTerm 内置 Launcher，也可以右键单击标签栏的 + 按钮，打开根据本机 Shell 和 Domain 生成的自定义菜单。

  • 最大化仍然保留系统窗口边界和任务栏行为；

GPU 选择器会枚举本机适配器并优先使用性能更高的组合。该设置适合高刷新率显示器，但会增加一定的 GPU 使用率。遇到黑屏、闪烁、驱动兼容问题时，可以临时将 config/appearance.lua 中的 front_end 改为 OpenGL，保存后重新验证。

4. 标签栏与状态栏

标签栏始终显示，即使当前只有一个 Tab。每个标签最多使用 23 列宽度，并根据运行环境显示：

  • 当前进程和终端标题；
  • WSL、管理员终端、调试面板、选择器等状态图标；
  • 后台任务的进度或错误状态；
  • 非活动 Tab 中尚未查看的输出数量。

右侧状态栏每秒更新一次，显示星期、时间和电池状态；没有电池的桌面设备只显示时间。左侧状态栏平时为空，在 Leader 键或 Key Table 激活时显示当前按键模式，便于判断后续按键会由哪一组规则处理。

四、快捷键记忆规则

这套配置没有沿用 WezTerm 默认快捷键，而是定义了两个跨平台修饰键：

配置名称 Windows/Linux macOS 本文写法
SUPER Alt Command Alt
SUPER_REV Alt+Ctrl Command+Ctrl Alt+Ctrl

Windows 下可以先记住以下规律：

  • Alt：直接操作当前窗口、Tab 或 Pane；
  • Alt+Ctrl：反向操作、移动操作或进入 WSL；
  • Alt+Ctrl+Space：Leader 键，用于进入持续的尺寸调整模式。

Leader 键自身的等待时间为 1 秒。按下 Alt+Ctrl+Space 后，需要在 1 秒内继续按 F 或 P。进入对应 Key Table 后，每次有效按键都会重新计算 1 秒超时。

七、Pane 分屏工作流

1. 创建分屏

快捷键 结果
Alt+\ 上下分屏，新 Pane 位于下方
Alt+Ctrl+\ 左右分屏，新 Pane 位于右侧

这里最容易产生误解：WezTerm 的 SplitVertical 表示沿垂直方向把空间分成上下两部分，而 SplitHorizontal 表示沿水平方向分成左右两部分。两个动作都使用 CurrentPaneDomain，因此：

  • 从 PowerShell Pane 分屏，新 Pane 继续运行 PowerShell；
  • 从 Ubuntu WSL Pane 分屏，新 Pane 继续留在 WSL Domain。

2. 在 Pane 之间移动

Alt+Ctrl+K 上
Alt+Ctrl+L 右

5. 打开 URL

配置提供两种方式：

  • 按住 Ctrl 并左键单击鼠标下方的链接；
  • 按 Alt+Ctrl+U，让 WezTerm 在当前 Pane 中识别 URL，选择后用系统默认程序打开。

链接规则可以识别普通 URL、圆括号、方括号、花括号和尖括号中的 URL，也可以将电子邮件地址识别为 mailto: 链接。

打开链接会调用系统关联程序。对于终端输出中的陌生域名、带令牌的 URL 或来自不可信命令的内容，应先检查目标地址，避免直接打开。

十、光标辅助与特殊输入

快捷键 功能
Alt+LeftArrow 向 Shell 发送行首控制序列
Alt+RightArrow 向 Shell 发送行尾控制序列
Alt+Backspace 发送 Ctrl+U，尝试清空当前输入行
Ctrl+Shift+N 输入 ♠
Ctrl+Shift+S 输入 ‽

前三项通过 SendString 向前台程序发送控制序列，其效果取决于 Shell 或终端程序是否解释该序列。Alt+Backspace 在 Bash 中通常可以清空行，但在 PowerShell 或 Command Prompt 中不一定生效。

Ctrl+Shift+N 和 Ctrl+Shift+S 是原仓库保留的特殊字符输入绑定。它们不是“新建窗口”和“保存”，使用带有这类通用快捷键的终端应用时需要留意冲突；如果没有输入这两个字符的需求，可以从 config/bindings.lua 中删除对应两行。

十一、三种典型工作流

1. Windows 与 WSL 并行开发

适合在 PowerShell 中运行 Windows 工具，同时在 WSL 中执行 Linux 构建、包管理或脚本。

2. 单个 Tab 内运行服务与日志

可以将编辑器、开发服务器和测试日志放在同一个 Tab 中。因为分屏继承当前 Domain，从 WSL Pane 创建的新 Pane 不会意外回到 Windows。

3. 长日志定位与复制

搜索负责定位，Copy Mode 负责精确选择，两者比反复拖动鼠标更适合长 Scrollback。

十六、总结

这套配置的核心不是单纯改变终端外观，而是建立一套统一的工作模型：

第一次使用时，优先掌握 F2、F3、Alt+T、Alt+Ctrl+T、两种分屏、Alt+Ctrl+H/J/K/L 和 F1。熟悉这些入口后，再逐步使用 Tab 重命名、背景选择、URL 快速打开和 Key Table。

配置文件是可执行的 Lua 代码，本机路径、Domain 名称和快捷键之间存在引用关系。修改时应一次只调整一个模块，保存后立即运行 show-keys 或打开 F12 验证。这样既能保留上游配置的完整功能，也能让 PowerShell、Git Bash 和 WSL 始终与当前机器的真实环境一致。
